# DJ Jesse Jay - Progressive Music Attack

![DJ Jesse Jay](https://img.shields.io/badge/Status-Active-brightgreen) ![Since](https://img.shields.io/badge/Since-1997-blue) ![License](https://img.shields.io/badge/License-Apache_2.0-orange)

**DJ Jesse Jay** ist ein passionierter DJ aus Zürich, der seit 1997 mit seiner einzigartigen Mischung aus **Progressive House, Techno und Electro** die Szene bereichert.

## 🎵 Was ich mache

- **Radio Shows**: Galaxy Space Night auf Radio LoRa (Zürich), Radio Stadtfilter (Winterthur) und Radio RaBe (Bern)
- **Club Auftritte**: Regelmäßige Gigs in Clubs und auf Festivals
- **Musikproduktion**: Kreation von Mixes und Sets mit radikaler Sensibilität

## 🌐 Website-Inhalte

Diese Website bietet:

- **📖 Biografie**: Informationen über meine musikalische Reise seit 1997
- **📅 Events**: Übersicht über vergangene und zukünftige Auftritte
- **🎶 Musik**: SoundCloud-Playlists und Radio-Archive
- **📝 Gästebuch**: Nachrichten von Fans und Freunden
- **📧 Kontakt**: Möglichkeiten zur Kontaktaufnahme

## 🛠 Technische Details

### Struktur
```
jessejay.ch/
├── index.html          # Startseite mit Biografie
├── events.html         # Veranstaltungen
├── music.html          # Musik und Streams
├── guestbook.html      # Gästebuch-Einträge
├── contact.html        # Kontaktformular
├── css/
│   └── style.css       # Haupt-Stylesheet
├── js/
│   └── main.js         # JavaScript-Funktionen
├── data/
│   ├── biography.json  # Biografie-Daten
│   ├── events.json     # Event-Daten
│   ├── guestbook.json  # Gästebuch-Einträge
│   ├── sounds.json     # Radio-Stream-Daten
│   └── images.json     # Bild-Daten
└── assets/
    └── images/         # Bilder und Logos
```

### Technologien
- **HTML5** mit semantischer Struktur
- **CSS3** mit Flexbox, Grid und responsivem Design
- **Vanilla JavaScript** (keine Frameworks, pure Performance)
- **JSON** für Datenspeicherung
- **Font Awesome** für Icons

### Features
- ✅ Vollständig responsiv (Mobile-First)
- ✅ Barrierefrei (WCAG 2.1 AA)
- ✅ SEO-optimiert
- ✅ Schnelle Ladezeiten
- ✅ Offline-fähig (statische Dateien)

## 🚀 Lokale Entwicklung

### Voraussetzungen
- Keine! Einfache HTML/CSS/JS-Dateien

### Starten
1. Repository klonen oder Dateien herunterladen
2. `index.html` in einem Browser öffnen
3. Fertig! 🎉

### Für Entwickler
```bash
# Lokale Entwicklung (mit Python)
python3 -m http.server 8000

# Mit Live-Reload (erfordert Node.js)
npx serve
```

## 📦 Deployment

### GitHub Pages
1. Repository auf GitHub pushen
2. In den Repository-Einstellungen GitHub Pages aktivieren
3. Branch `main` und Ordner `/root` auswählen
4. Website ist unter `https://<username>.github.io/jessejay.ch/` verfügbar

### Eigenes Hosting
Einfach alle Dateien auf deinen Webserver hochladen. Keine Datenbank oder Server-Side-Code erforderlich!
